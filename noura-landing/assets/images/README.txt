Optional images live here:

- Testimonial photos: reference them from the `avatar` field of an
  entry in the `testimonials` array in js/data.js, e.g.
      avatar: "assets/images/ahmed.jpg"
  Leave `avatar: ""` (the default) to show a clean gold initial badge
  instead — that always looks finished, so adding real photos is
  optional, not required.

- Short-video thumbnails: reference them from the `thumbnail` field in
  the `shortVideos` array the same way. Leave "" to use the built-in
  gradient placeholder.
